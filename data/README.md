# Dataset

Este repositorio **no incluye una copia del dataset**.

El notebook descarga automáticamente:

`daily-min-temperatures.csv`

Desde:

`https://raw.githubusercontent.com/jbrownlee/Datasets/master/daily-min-temperatures.csv`

El conjunto contiene 3.650 observaciones de temperaturas mínimas diarias en Melbourne entre 1981 y 1990. La fuente histórica se atribuye al **Australian Bureau of Meteorology** y el archivo utilizado por el proyecto se obtiene desde el repositorio público de datasets de Jason Brownlee / Machine Learning Mastery.

El repositorio espejo utilizado no muestra de forma clara una licencia específica de redistribución para este archivo concreto. Por ese motivo, el CSV no se versiona aquí y se mantiene únicamente la referencia a la fuente empleada por el notebook.
