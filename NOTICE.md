# Notice

## Dataset

Este proyecto utiliza el conjunto **Daily Minimum Temperatures in Melbourne**, correspondiente a temperaturas mínimas diarias registradas en Melbourne entre 1981 y 1990.

- Fuente histórica atribuida: Australian Bureau of Meteorology.
- Archivo empleado por el notebook: repositorio público `jbrownlee/Datasets` de Jason Brownlee / Machine Learning Mastery.
- URL de descarga utilizada:
  `https://raw.githubusercontent.com/jbrownlee/Datasets/master/daily-min-temperatures.csv`

El dataset no se incluye en este repositorio porque no se ha identificado en el repositorio espejo una licencia específica y suficientemente clara para redistribuir este archivo concreto.
